# @knowledge 欢迎来到 Marqdo

Marqdo 把 Markdown 当作可执行文档的语言：标题声明 `@exec` / `@knowledge` 模式，
强调、斜体与行内代码是**等价的单语句载体**，而 `if` / `else` / `while` / `end` /
`return` 决定真正的操作。

| 阅读态 | 内容 | 是否执行 |
| --- | --- | --- |
| 文档 | 原始 Markdown 排版 | 否 |
| 源码 | 逐行原文，包含全部标记 | 否 |
| 运行 | 用户显式确认后才出现 | 是（需要确认） |

继续阅读：[语法演示](./guide.mq.md)。

> 这份欢迎页只是 `view.json` 显式指定的站点首页，普通 `welcome` 文件名不会自动变成 Hero。
